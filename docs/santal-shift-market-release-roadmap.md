# Санталь Смена: дорожная карта до 100% готовности

## Текущая оценка

Публичный рынок: 74%.

Закрытый пилот: 84%.

Причина разницы: приложение опубликовано, тесты проходят, Telegram-бот и Mini App работают. После агентского аудита добавлены fail-closed проверки для production: без Google Sheets приложение больше не имитирует успешную работу в demo-памяти, webhook без секрета не принимает запросы, а смены чужих филиалов запрещены на backend-уровне. Оставшиеся P0-блокеры внешние: постоянное хранилище Google Sheets еще не включено в production-среде, а Telegram token должен быть перевыпущен перед запуском пользователей.

## Агентский аудит

Роли ревьюеров:

- Product/UX агент проверил пути сотрудника и пустые состояния.
- Backend/Synchronization агент проверил Google Sheets как runtime-хранилище.
- Telegram/Security/Release агент проверил webhook, секреты и deploy gates.
- QA/Test агент проверил покрытие тестами и smoke-сценарии.

Закрыто текущим проходом:

- [x] Production без Google Sheets больше не открывает demo/default admin session.
- [x] Production-мутации смен блокируются, если хранилище не подключено.
- [x] UI показывает конкретное сообщение API при ошибке загрузки.
- [x] Production webhook fail-closed, если `TELEGRAM_WEBHOOK_SECRET` не настроен.
- [x] Telegram API client fail-closed, если bot token отсутствует.
- [x] Backend запрещает брать смену филиала, который не доступен сотруднику.
- [x] Readiness endpoint показывает процент готовности, критичные блокеры и next actions.
